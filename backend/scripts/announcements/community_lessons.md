# Vos enfants peuvent maintenant apprendre avec vos leçons ✨

Bonjour,

Explorito reste un petit projet de famille, fait le soir pour nos enfants — et
pour les vôtres. Voici la nouveauté du moment.

## Ce qui change

Vous pouvez désormais **créer vos propres leçons** avec l'IA que vous utilisez
déjà (ChatGPT, Claude, Gemini…), les importer dans Explorito, et les proposer à
toute la communauté. Une leçon sur les dinosaures, les additions, les volcans,
le prénom du chat : ce qui accroche votre enfant marche souvent pour les autres.

## Trois étapes pour essayer

- Demandez à votre IA un pack de leçons au format Explorito (le tutoriel donne
  le texte exact à copier-coller).
- Déposez le fichier obtenu dans **Mes leçons**, dans votre espace parent.
- Relisez l'aperçu, corrigez si besoin, puis soumettez-le.

Le tutoriel complet, avec des exemples, est ici :
[Créer une leçon avec votre IA]({PUBLIC_APP_URL}/tutoriel/lecons-communautaires)

## Et côté sérénité

Chaque pack partagé est **relu avant d'être visible**, et rien n'arrive
automatiquement chez votre enfant : vous activez, enfant par enfant, ce que vous
voulez lui donner. Vous gardez la main à tout moment.

Une seule règle importante : **pas de données personnelles dans les leçons** —
ni nom de famille, ni école, ni photo, ni adresse. Un prénom seul suffit
largement pour rendre un exercice attachant.

Si vous essayez, écrivez-moi ce qui coince : c'est en corrigeant vos retours
que l'application avance. Et si vous n'avez pas envie de créer quoi que ce soit,
c'est très bien aussi — vos enfants profiteront des leçons des autres 🙂

Bonne exploration,
